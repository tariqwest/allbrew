## How to distinguish permission vs infra

- **Permission stall:** Warp UI shows `Allow this command?` waiting on `Allow` button; `agent-index.jsonl` would show `vmHelperUsed:false`, no `vm-install.log` created, `blockedReason: warpdotdev/warp not trusted` or `trust warning`. Fix: widen allowlist per §1 (remove `bash/sh/rm/curl/ssh` from `command_denylist`).
- **Infra block:** `vmHelperUsed:true`, `vm-install.log` exists (or `0B` + `hygiene` shows `CLEANUP_OK`), `vm-meta.json: diskAvail` or `phase: acquiring-prefix`, summary cites sparsebundle/lock/ENOSPC — not a `command_denylist` hit. Fix: hygiene/retry per table above; **do not** put `sudo`/`rm -rf /` on allowlist to “fix” infra.
